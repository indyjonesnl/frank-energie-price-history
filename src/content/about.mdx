# About

This is an unofficial archive of Frank Energie's published dynamic-tariff prices. It exists because Frank publishes hourly prices but does not provide a long-term browsable history, and consumers may want to look back at past months to understand the value of dynamic billing.

This site is **not affiliated with Frank Energie**. All price data is fetched from Frank's public GraphQL API, stored verbatim in this project's GitHub repository, and republished as charts and tables.
